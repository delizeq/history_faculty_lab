# Сайт Факультету історії (лабораторна з веб-програмування)

Навчальний проєкт на Django: сайт вигаданого Факультету історії (кафедри, спеціальності, викладачі)
та розділ програм академічного обміну (`/exchange/`).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py makemigrations faculty
python manage.py migrate
python manage.py loaddata initial_data
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ · Адмінка: http://127.0.0.1:8000/admin/

## Перевірка відкату міграцій обміну

```bash
python manage.py migrate exchange zero
python manage.py migrate
```

Відповіді на питання до завдання: [ANSWERS.md](ANSWERS.md).

## Аналіз існуючих сайтів

Під час підготовки проєкту я проаналізував сайти Факультету гуманітарних наук та Факультету інформатики НаУКМА. Більшості з них бракує зручного та структурованого розділу для програм академічного обміну: інформація часто подана у вигляді звичайних новин або довгих завантажувальних файлів без системного фільтра. У своєму проєкті я реалізував окремий розділ обміну (`/exchange/`) зі зручним переліком програм, динамічним відображенням статусу прийому документів та можливістю чіткого розмежування ВНЗ за країною і кількістю місць.
